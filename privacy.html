データの収集について

PhotoParcel Select は、いかなる個人情報・利用データも収集しません。

  • ユーザーの写真・ファイルは、すべてお使いの Mac・iPad・iPhone の中だけで処理されます。
  • アプリは外部サーバーとの通信を一切行いません。
  • 解析ツール・広告・トラッキングは含まれていません。

ファイルへのアクセスについて

本アプリは App Sandbox 内で動作します。アクセスできるのは、ユーザーが「フォルダを開く」で明示的に選択したフォルダのみです。選択したフォルダへのアクセス権は、次回起動時のためにセキュリティスコープ付きブックマークとしてお使いの端末内にのみ保存されます。

ファイルの書き込みについて

RAW の写真ファイルは書き換えません。星の評価は、選択したフォルダ内に 写真名.xmp という別ファイルとして保存されます。JPEG だけは、現像ソフトが別ファイルの XMP を読まないため、星の評価を写真ファイルの中に書き込みます。書き換えるのは星の情報だけで、画像そのものや撮影情報は変更しません。すでに XMP ファイルが存在する場合は評価の箇所のみを書き換え、キーワードや現像設定などの他の情報は変更しません。

他アプリとの連携について

macOS 版では、同じ開発者による PhotoParcel がインストールされている場合に限り、フォルダの受け渡しを行えます。受け渡されるのはフォルダの場所のみで、写真の内容が外部に送信されることはありません。

PhotoParcel Select Privacy Policy

Last updated: November 24, 2026

Data collection

PhotoParcel Select does not collect any personal information or usage data.

  • Your photos and files are processed only on your Mac, iPad or iPhone.
  • The app does not communicate with any external server.
  • The app contains no analytics, advertising or tracking.

File access

The app runs in the App Sandbox. It can access only the folder you explicitly choose with "Open Folder". Access to that folder is stored on your device as a security-scoped bookmark so the folder can be reopened next time.

Writing files

RAW photo files are never modified. Star ratings are saved in the chosen folder as separate files named photo name.xmp. For JPEG files only, the rating is written inside the photo file, because photo editors do not read separate XMP files for JPEG. Only the rating is changed; the image and the shooting information are left as they are. If an XMP file already exists, only the rating is updated, and other information such as keywords and develop settings is left unchanged.

Working with other apps

On macOS, if PhotoParcel by the same developer is installed, the app can hand a folder over to it. Only the location of the folder is passed; the contents of your photos are never sent anywhere.

Changes to this policy

Any changes to this policy will be announced on this page.
